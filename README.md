# Nitro Drift

**English** | [Türkçe](README.tr.md)

A single-player, endless arcade racing game made with Unity.<br>
Everything in the game — cars, road, scenery, effects, engine sounds and music — is generated by code. No ready-made models, textures or sound files.

## About

Get as far as you can before time runs out: drift, burn nitro, weave through traffic and beat your record. Checkpoint gates add time, drift chains build your combo, and traffic gets denser the longer you survive.

## Why I Built This

Nitro Drift is my first finished Unity game. I built it to learn game development in Unity: vehicle physics, procedural generation, audio synthesis and building a complete game loop from menu to game over.

I used AI tools during development to speed things up, explain Unity concepts and help track down bugs. The game design, testing, tuning and decisions about how the game should look and feel were mine.

## Features

- **Race against the clock** — time counts down, checkpoint gates add time
- **Score** — distance + drift chain × combo + gate bonus, plus near-miss and airtime bonuses
- **2 maps** — a winding road and a highway with oncoming traffic (a growing score multiplier while you stay in the wrong lane, tunnels and bridges)
- **4 landscapes** — forest, desert, snowy mountains and coast
- **Time and weather** — day, sunset and night; clear or rain with wet road reflections and lightning
- **3 cars** — super sports car, muscle car (V8 sound) and tractor (diesel sound), each with its own stats
- **Garage** — buy cars with the credits you earn, upgrade engine / nitro / grip and pick your color
- **Pickups and ramps**, traffic that gets denser over time, a statistics screen and synthwave music in the menu
- **Procedural everything** — 3D models, scenery, engine sounds and music are all generated in code
- **Local save** — credits, cars, records and settings are stored only on your own computer

## Download and Play (Windows)

1. Download the latest `.zip` from the **Releases** section on the right, or get it on [itch.io](https://cannes035.itch.io/nitro-drift).
2. Extract the zip into a folder (right click → Extract All).
3. Run `NitroDrift.exe`.

> If Windows shows an "unknown publisher" warning, click **More info → Run anyway**.

## Opening the Project in Unity

- Requires **Unity 6000.6.6f1** (Universal Render Pipeline); don't open it with a different version.
- Unity Hub → **Add project from disk** → select this folder.
- Open the `Assets/Scenes/SampleScene.unity` scene and press **Play**.
- For a Windows build, use the top menu **Yarış → Windows için Build Al** ("Make Windows Build").
