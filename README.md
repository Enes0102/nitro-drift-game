# NITRO DRIFT

**[English](#english) · [Türkçe](#türkçe)**

---

## English

A single-player, endless arcade racing game made with Unity. Get as far as you can before time runs out:
drift, burn nitro, weave through traffic and beat your record.

Everything in the game (cars, road, trees, mountains, effects, engine sounds, music) is **generated by code**;
no ready-made models, textures or sound files were used.

### Download and play (Windows)

1. Download the latest `.zip` from the **Releases** section on the right.
2. Extract the zip into a folder (right click → Extract All).
3. Run `NitroDrift.exe`.

> If Windows shows an "unknown publisher" warning, click **More info → Run anyway**.

### Controls

| Key | Action |
| --- | --- |
| W / S (or arrow keys) | Throttle / brake |
| A / D (or arrow keys) | Steering |
| Space | Drift |
| Shift | Nitro |
| Esc / P | Pause |

In the menu: Enter / Space to start, G garage, Tab settings, I statistics.

> The in-game menus are in Turkish.

### Features

- **Race against the clock:** time counts down, checkpoint gates add time.
- **Score:** distance + drift chain × combo + gate bonus, plus near-miss and airtime bonuses.
- **2 maps:** a winding road and a highway with oncoming traffic (a growing score multiplier while you stay in the wrong lane, tunnels and bridges).
- **4 landscapes:** forest, desert, snowy mountains, coast.
- **Time and weather:** day, sunset, night; clear or rain (wet road reflections, lightning).
- **3 cars:** super sports car, muscle car (V8 sound) and tractor (diesel sound), each with its own stats.
- **Garage:** buy cars with the credits you earn, upgrade engine / nitro / grip, pick your color.
- **Pickups and ramps**, traffic that gets denser over time, a statistics screen, synthwave music in the menu.

Your progress (credits, cars, records, settings) is stored only on your own computer.

### Opening the project in Unity

- Requires **Unity 6000.6.6f1** (Universal Render Pipeline); don't open it with a different version.
- Unity Hub → **Add project from disk** → select this folder.
- Open the `Assets/Scenes/SampleScene.unity` scene and press **Play**.
- For a Windows build, use the top menu **Yarış → Windows için Build Al** ("Make Windows Build").

## Türkçe

Unity ile yapılmış, tek oyunculu, sonsuz bir arcade yarış oyunu. Süre bitmeden olabildiğince uzağa git,
drift at, nitro yak, trafiğin arasından makas at ve rekorunu kır.

Oyundaki her şey (arabalar, yol, ağaçlar, dağlar, efektler, motor sesleri, müzik) **kodla üretiliyor**;
dışarıdan hazır model, doku ya da ses dosyası kullanılmadı.

### İndir ve oyna (Windows)

1. Sağdaki **Releases** bölümünden son sürümün `.zip` dosyasını indir.
2. Zip'i bir klasöre çıkar (sağ tık → Tümünü ayıkla).
3. `NitroDrift.exe` dosyasını çalıştır.

> Windows "bilinmeyen yayıncı" uyarısı verirse **Ek bilgi → Yine de çalıştır**'a bas.

### Kontroller

| Tuş | İşlev |
| --- | --- |
| W / S (ya da oklar) | Gaz / fren |
| A / D (ya da oklar) | Direksiyon |
| Space | Drift |
| Shift | Nitro |
| Esc / P | Duraklat |

Menüde: Enter / Space başla, G garaj, Tab ayarlar, I istatistikler.

### Oyunda neler var

- **Süreye karşı yarış:** süre geri sayar, kontrol noktası kapıları süre ekler.
- **Puan:** mesafe + drift zinciri × kombo + kapı bonusu, yakın geçiş ve uçuş bonusları.
- **2 harita:** virajlı yol ve karşı trafikli otoyol (ters şeritte kaldıkça artan puan çarpanı, tüneller ve köprüler).
- **4 manzara:** orman, çöl, karlı dağ, sahil.
- **Zaman ve hava:** gündüz, gün batımı, gece; açık hava ya da yağmur (ıslak yol yansımaları, şimşek).
- **3 araba:** süper spor, muscle (V8 sesi) ve traktör (dizel sesi); her birinin kendi özellikleri var.
- **Garaj:** kazandığın kredilerle araba satın al, motor / nitro / yol tutuş yükseltmeleri yap, rengini seç.
- **Bonuslar ve rampalar**, giderek kalabalıklaşan trafik, istatistik ekranı, menüde synthwave müzik.

İlerlemen (kredi, arabalar, rekorlar, ayarlar) sadece kendi bilgisayarında saklanır.
